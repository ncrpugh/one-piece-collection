# Features

## Collection

- I want to seamlessly add cards to my collection
- I want to quickly find a specific card
- I want to know if I own a card
- I want to know how many copies of a card I own
- I want to know how much of a set I own (percentage)
- I want to know about special cards
    - How many alt arts I have
    - How many leader alt arts
    - How many winner cards
    - How many promotionals 
    - etc.
- I want to track trades or purchases 
- I want to be able to easily remove cards
- I want to be able to have a rough value of collection
- I want to give a field for physical location of cards in like metadata or whatever (probably a text field or something and user could input binder a, b, c, 1, 2, 3 or whatever so they know where the card is or if it is in bulk storage or if it is in a deck etc.)
- I want the interface to be user friendly and pleasant to use
- I want load & wait times to be minimal to none
- I want to be able to give access to collection to friends or something so you can track each others collections, whether for progress or for deck building or for whatever
- I want there to be language differences so you set a default language cards are to be entered in but then if you have cards in different languages you can select the alternate language it is in and this is stored separately than same card in different language

## Decks

- I want to upload a deck or scrape a common or most popular deck from... 
- I want to compare cards in collection to these decks so I know percentage of cards I have of deck, what I am missing etc.
- I want to know how many / which decks I could currently make using my collection
- I want to know how much it would roughly cost to 'complete' the deck (obtain the remaining cards I don't have)
- I want a feature where I could get somebody else's collection and almost combine it with mine in temporary storage so that we could see between these accounts how much of decks do we have collectively
- I want all the deck building features to have the option of doing it with one set of cards i.e. if I have 4 of a card I can build all decks at the same time using this card or with how many decks you could physically make i.e. if I need a playset of the same card for multiple decks then I would need 4 * the number of decks of this card.



These features mostly exist already but they aren't the most automatic or user-friendly I'm thinking of sites such as car.d.kaizoku where some of the features are behind a paywall and some of the features just isn't quite what I think a player is looking for, while it is good, it isn't quite perfect.

## Search

- I want to be able to comprehensively search for cards by attribute, power, cost, counter, name, card type (character, event, stage, leader), card faction / family, set, rarity, block, colour, trigger, key words (on play, blocker, when attacking, on k.o. etc.), rough effects, maybe image / image description or something
- I want search features to allow expressions / comparisons (i.e. greater than 2000 power, after op15, less than 8 cost etc.) 
- I want to be able to add cards from searches to a deck or a list or some sort of save this knowledge for later place.
- I want to be able to search for alt arts or at least someway to distinguish search for alt or standard version maybe a tick box for show alts
